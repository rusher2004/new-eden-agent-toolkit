# Auth Core (urlscheme + sso) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fully working, tested character-auth flow — PKCE, browser launch, per-OS `eveauth-neat://`
registration, cross-process socket handoff, ESI token exchange, and persistence via `creds/` —
driven entirely by tests in this plan. No MCP exposure yet (that's the next plan, "MCP server &
character tools").

**Architecture:** Two new packages. `urlscheme/` registers `eveauth-neat://` as this machine's
handler for the scheme, one build-tag-separated file per OS (macOS needs a real compiled Cocoa/Swift
wrapper, embedded into the Go binary via `//go:embed`; Windows writes registry keys; Linux writes a
`.desktop` file). `sso/` owns the OAuth2/PKCE flow: a Unix-socket listener receives the callback
from a second, OS-launched process, exchanges the code via `goesi-openapi`, and persists the
refresh token via `creds/` (already built).

**Tech Stack:** Go 1.26.1, `github.com/fnt-eve/goesi-openapi` (OAuth2/PKCE + JWT), `golang.org/x/oauth2`,
`github.com/golang-jwt/jwt/v5`, `golang.org/x/sys/windows/registry` (Windows only), Swift/`swiftc`
(macOS wrapper only, not a Go dependency).

## Global Constraints

(Copied verbatim from `docs/superpowers/specs/2026-07-23-foundation-design.md`, plus facts verified
during this plan's research.)

- Module: `github.com/rusher2004/new-eden-agent-toolkit`. Go 1.26.1.
- `CGO_ENABLED=0` for the `neat` Go binary itself — every Go dependency here is pure Go. (The
  macOS Swift wrapper is a *separate*, non-Go executable embedded as data via `//go:embed`; it does
  not affect the Go binary's CGO status.)
- Flat package structure, no `internal/`.
- Redirect URI: custom scheme `eveauth-neat://callback`, decided over loopback HTTP. No fallback —
  if OS registration didn't succeed, `add_character` fails with a clear, specific error.
- Callback handoff: local Unix domain socket at `~/.neat/run/callback.sock`, `0600` permissions. If
  a listener already holds that path, a second `add_character` call fails immediately with a clear
  "already in progress" error rather than colliding.
- Blocking wait for the callback: up to 5 minutes, a firm decision, not a placeholder.
- Token lifecycle ownership: `sso/` owns exchange, refresh, and persistence via `creds/`. Nothing
  else touches `goesi-openapi` directly.
- `creds.Service = "neat"`, `creds.SaveCharacterRefreshToken(characterID int32, token string) error`,
  `creds.CharacterRefreshToken(characterID int32) (string, error)` — already built (Plan 1), reused
  here unchanged.
- `fmt.Errorf("operation: %w", err)` wrapping everywhere; never discard an error.
- External test packages by default (`package foo_test`); table-driven where a table naturally
  fits, independent named tests otherwise; stdlib-only (no testify) for our own Go code.
- **Verified fact (this plan's own research, not the original spec):** `goesi.ESIJWTClaims.CharacterID()`
  returns `int64`. `creds`/`config` already commit to `int32` character IDs (Plan 1, merged). This
  plan's `sso/` package is responsible for the bounds-checked `int64`→`int32` conversion at that
  boundary.
- **Verified fact:** a bare executable cannot receive macOS's `kAEGetURL` Apple Event — only a real
  `NSApplication`-based app can. The macOS `urlscheme` implementation therefore embeds a compiled
  Swift wrapper (confirmed to compile with `swiftc` and `import Carbon` — not `import Carbon.Carbon`,
  which doesn't exist as a module — on this toolchain: Swift 6.3.3 / Xcode toolchain).
- **Deferred, not part of this plan:** the `esi/` package. Nothing in `add_character` /
  `list_characters` / `remove_character` (this plan, or the next) calls a live ESI endpoint —
  character ID/name come from the JWT claims directly. `esi/` has no caller yet; build it when the
  first domain-specific ESI tool needs it.
- **Known, accepted gap:** Windows and Linux `urlscheme` registration logic cannot be executed on
  this (macOS) development machine — only cross-compiled (`GOOS=windows`/`GOOS=linux go build`/
  `go vet`). Their *pure content-building* logic (the registry command string, the `.desktop` file
  text) is written as OS-untagged, fully cross-platform-testable functions specifically so this gap
  is as small as possible. The actual OS mutation (registry writes, `xdg-mime`) is not exercised by
  an automated test in this plan.

```go
// Package urlscheme registers eveauth-neat:// as this machine's handler for
// the ESI OAuth2 redirect, one implementation per OS (see the
// urlscheme_{darwin,windows,linux}.go build-tag-separated files).
package urlscheme

import (
	"fmt"
	"os/exec"
)

// Scheme is the custom URI scheme registered as the ESI OAuth redirect
// target. ESI's app settings allow schemes starting with "eveauth".
const Scheme = "eveauth-neat"

// commandRunner invokes an external OS command. Overridable in tests so
// registration logic can be verified without actually invoking lsregister,
// reg, or xdg-mime.
var commandRunner = func(name string, args ...string) error {
	return exec.Command(name, args...).Run()
}

// Register installs eveauth-neat:// as this machine's OS-level handler for
// the scheme, pointing at launcherPath. Idempotent: safe to call on every
// `neat mcp` startup.
func Register(launcherPath string) error {
	if err := register(launcherPath); err != nil {
		return fmt.Errorf("register %s handler: %w", Scheme, err)
	}
	return nil
}

// buildWindowsCommand returns the shell\open\command registry value for the
// given launcher path. Pure string formatting — no Windows-specific types
// — so it's testable on any OS, even though only urlscheme_windows.go
// actually writes it to the registry.
func buildWindowsCommand(launcherPath string) string {
	return fmt.Sprintf(`"%s" callback-handler "%%1"`, launcherPath)
}

// buildDesktopFileContent returns the contents of the .desktop file Linux
// uses to register a URI scheme handler. Pure string formatting — testable
// on any OS, even though only urlscheme_linux.go actually writes it.
func buildDesktopFileContent(launcherPath string) string {
	return fmt.Sprintf(`[Desktop Entry]
Type=Application
Name=Neat URL Handler
Exec=%s callback-handler %%u
NoDisplay=true
MimeType=x-scheme-handler/%s;
`, launcherPath, Scheme)
}
```

**Context:** macOS delivers custom-URL-scheme activations as a `kAEGetURL` Apple Event, which only
a real `NSApplication`-based app can receive — a bare executable cannot, confirmed by compiling and
testing the snippet below during this plan's own research. `main.swift` is a minimal such app: it
registers an Apple Event handler, extracts the URL, execs `~/.neat/bin/neat callback-handler <url>`,
and exits. It's compiled once via `swiftc` (available on this machine: Swift 6.3.3) into a real
`.app` bundle, which is then embedded into the `neat` Go binary via `//go:embed` — so it ships
automatically wherever `neat` does, with no separate release asset or runtime compilation needed.

- [ ] **Step 1: Write the Swift wrapper source**

Create `urlscheme/macos/main.swift`:
```swift
import Cocoa
import Carbon

class AppDelegate: NSObject, NSApplicationDelegate {
    func applicationDidFinishLaunching(_ notification: Notification) {
        NSAppleEventManager.shared().setEventHandler(
            self,
            andSelector: #selector(handleGetURL(event:replyEvent:)),
            forEventClass: AEEventClass(kInternetEventClass),
            andEventID: AEEventID(kAEGetURL)
        )
    }

    @objc func handleGetURL(event: NSAppleEventDescriptor, replyEvent: NSAppleEventDescriptor) {
        defer { NSApp.terminate(nil) }

        guard let urlString = event.paramDescriptor(forKeyword: AEKeyword(keyDirectObject))?.stringValue else {
            return
        }

        let launcherPath = NSHomeDirectory() + "/.neat/bin/neat"
        let process = Process()
        process.executableURL = URL(fileURLWithPath: launcherPath)
        process.arguments = ["callback-handler", urlString]
        try? process.run()
        process.waitUntilExit()
    }
}

let app = NSApplication.shared
let delegate = AppDelegate()
app.delegate = delegate
app.run()
```

```go
//go:build darwin

package urlscheme

import (
	"embed"
	"fmt"
	"io/fs"
	"os"
	"path/filepath"
)

//go:embed macos/build/NeatURLHandler.app
var bundleFS embed.FS

const bundleFSRoot = "macos/build/NeatURLHandler.app"

// register ignores launcherPath: the embedded Swift wrapper hardcodes
// ~/.neat/bin/neat internally (see urlscheme/macos/main.swift) since it's
// compiled once and never varies per-install. The parameter still exists
// so this function's signature matches Windows/Linux's register(), which
// do need it.
func register(_ string) error {
	home, err := os.UserHomeDir()
	if err != nil {
		return fmt.Errorf("resolve home directory: %w", err)
	}
	bundlePath := filepath.Join(home, ".neat", "NeatURLHandler.app")

	if err := extractBundle(bundlePath); err != nil {
		return fmt.Errorf("extract bundle: %w", err)
	}

	if err := commandRunner("lsregister", "-f", bundlePath); err != nil {
		return fmt.Errorf("run lsregister: %w", err)
	}
	return nil
}

// extractBundle copies the embedded .app bundle to destPath, overwriting
// anything already there (idempotent — safe to call on every neat mcp
// startup, e.g. after a binary update changes the embedded wrapper).
func extractBundle(destPath string) error {
	return fs.WalkDir(bundleFS, bundleFSRoot, func(path string, d fs.DirEntry, err error) error {
		if err != nil {
			return err
		}
		rel, err := filepath.Rel(bundleFSRoot, path)
		if err != nil {
			return fmt.Errorf("compute relative path for %s: %w", path, err)
		}
		target := filepath.Join(destPath, rel)

		if d.IsDir() {
			return os.MkdirAll(target, 0o755)
		}

		data, err := bundleFS.ReadFile(path)
		if err != nil {
			return fmt.Errorf("read embedded file %s: %w", path, err)
		}
		mode := os.FileMode(0o644)
		if filepath.Base(path) == "NeatURLHandler" {
			mode = 0o755
		}
		if err := os.MkdirAll(filepath.Dir(target), 0o755); err != nil {
			return fmt.Errorf("create directory for %s: %w", target, err)
		}
		return os.WriteFile(target, data, mode)
	})
}

// SetCommandRunnerForTest overrides the OS-command runner for tests.
func SetCommandRunnerForTest(fn func(name string, args ...string) error) {
	commandRunner = fn
}

// ResetCommandRunnerForTest restores the real OS-command runner.
func ResetCommandRunnerForTest() {
	commandRunner = func(name string, args ...string) error {
		return realCommandRunner(name, args...)
	}
}
```

`SetCommandRunnerForTest`/`ResetCommandRunnerForTest` need a real, callable default to reset to —
`urlscheme.go`'s `commandRunner` var already holds one, but resetting needs a stable reference to
the *original* function, not whatever `commandRunner` currently is. Fix `urlscheme/urlscheme.go`
(Task 1's file) to name the real implementation so it can be restored:

```go
// ResetCommandRunnerForTest.

	return exec.Command(name, args...).Run()
}

var commandRunner = realCommandRunner
```

```go
//go:build windows

package urlscheme

import (
	"fmt"

	"golang.org/x/sys/windows/registry"
)

func register(launcherPath string) error {
	baseKey, _, err := registry.CreateKey(registry.CURRENT_USER, `Software\Classes\`+Scheme, registry.ALL_ACCESS)
	if err != nil {
		return fmt.Errorf("create base registry key: %w", err)
	}
```

### Task 6: `sso` — Unix socket callback handoff

**Corrected mid-execution — read this before the rest of the task.** The first implementation of
this task (single socket, dial-then-close liveness probe against the same socket
`receiveCallback` accepts on) had a real, non-theoretical race: if flow A is blocked in
`receiveCallback`'s `Accept()` when flow B calls `listenForCallback` again, B's liveness probe
connection can itself be the one A's single `Accept()` picks up — silently corrupting A with an
empty payload instead of the real callback, while B correctly gets `ErrAddCharacterInProgress`.
Found and confirmed by direct code reading during this plan's execution, not a hypothetical.

**Fix:** two separate Unix sockets instead of one — a **lock** socket (`~/.neat/run/callback.lock`,
bound but never `Accept()`-ed; purely a liveness signal for the collision probe) and a **delivery**
socket (`~/.neat/run/callback.sock`, `Accept()`-ed exactly once, by `receiveCallback`, as before). A
second call's collision probe now only ever touches the lock socket — if the lock is already held,
the second call fails before it ever attempts to open (or touch) the delivery socket, so it can
never consume the first flow's real callback connection. Binding a Unix socket succeeds as soon as
it's in the OS's listen backlog, even before `Accept()` is called — this is why probing the lock
socket (dial-then-close, never accepted) correctly detects "in use" without requiring the holder to
ever accept anything on it.

**Files:**
- Modify: `sso/sso.go` (add lock + delivery path resolution)
- Create: `sso/socket.go`
- Test: `sso/socket_test.go`

- Produces:
  - `var sso.ErrAddCharacterInProgress error`

    (package-private) — acquires the lock, then opens the delivery socket
  - `(*callbackListener) Close() error` — releases both sockets and removes both files
  - `sso.receiveCallback(l net.Listener, timeout time.Duration) (string, error)` (package-private)

```go
package sso

import (
	"errors"
	"fmt"
	"io"
	"net"
	"os"
	"path/filepath"
	"time"
)

// ErrAddCharacterInProgress is returned when add_character is called while
// another add-character flow is already waiting for its callback.
var ErrAddCharacterInProgress = errors.New("a character-add flow is already in progress")

// callbackListener bundles the two sockets one add-character flow holds: a
// lock socket (bound but never Accept()-ed — purely a liveness signal, so a
// second concurrent call's collision probe can never be mistaken for the
// real callback) and a delivery socket (Accept()-ed exactly once, by
// receiveCallback).
type callbackListener struct {
	lock         net.Listener
	delivery     net.Listener
	lockPath     string
	deliveryPath string
}

// Close releases both sockets and removes their files.
func (c *callbackListener) Close() error {
	var errs []error
	if err := c.delivery.Close(); err != nil {
		errs = append(errs, fmt.Errorf("close delivery socket: %w", err))
	}
	if err := os.Remove(c.deliveryPath); err != nil && !errors.Is(err, os.ErrNotExist) {
		errs = append(errs, fmt.Errorf("remove delivery socket file: %w", err))
	}
	if err := c.lock.Close(); err != nil {
		errs = append(errs, fmt.Errorf("close lock socket: %w", err))
	}
	if err := os.Remove(c.lockPath); err != nil && !errors.Is(err, os.ErrNotExist) {
		errs = append(errs, fmt.Errorf("remove lock socket file: %w", err))
	}
	return errors.Join(errs...)
}

// listenForCallback acquires the add-character lock at lockPath and opens
// the delivery socket at deliveryPath, failing with
// ErrAddCharacterInProgress if another flow already holds the lock. A lock
// or delivery socket file left behind by a crashed previous run (nothing
// listening) is treated as stale and removed.
//
// The lock and delivery sockets are deliberately separate: if they were the
// same socket, a second call's liveness probe (a dial-then-close) could
// itself be accepted by the first call's single receiveCallback Accept(),
// silently corrupting the first (legitimate) flow with an empty payload
// instead of the real callback.
func listenForCallback(lockPath, deliveryPath string) (*callbackListener, error) {
	if err := os.MkdirAll(filepath.Dir(lockPath), 0o700); err != nil {
		return nil, fmt.Errorf("create run directory: %w", err)
	}

	lock, err := bindExclusive(lockPath)
	if err != nil {
		return nil, err
	}

	delivery, err := bindExclusive(deliveryPath)
	if err != nil {
		lock.Close()
		os.Remove(lockPath)
		return nil, fmt.Errorf("open delivery socket: %w", err)
	}

	return &callbackListener{lock: lock, delivery: delivery, lockPath: lockPath, deliveryPath: deliveryPath}, nil
}

// bindExclusive binds a Unix socket at path. An existing file with nothing
// listening behind it is treated as stale (removed and rebound); an
// existing file with something actively listening returns
// ErrAddCharacterInProgress.
func bindExclusive(path string) (net.Listener, error) {
	if conn, err := net.DialTimeout("unix", path, 200*time.Millisecond); err == nil {
		conn.Close()
		return nil, ErrAddCharacterInProgress
	}

	if err := os.Remove(path); err != nil && !errors.Is(err, os.ErrNotExist) {
		return nil, fmt.Errorf("remove stale socket %s: %w", path, err)
	}

	l, err := net.Listen("unix", path)
	if err != nil {
		return nil, fmt.Errorf("listen on %s: %w", path, err)
	}
	if err := os.Chmod(path, 0o600); err != nil {
		l.Close()
		return nil, fmt.Errorf("set socket permissions: %w", err)
	}
	return l, nil
}

// receiveCallback blocks until a callback-handler process delivers the
// redirect URL via DeliverCallback, or timeout elapses.
func receiveCallback(l net.Listener, timeout time.Duration) (string, error) {
	type result struct {
		url string
		err error
	}
	ch := make(chan result, 1)

	go func() {
		conn, err := l.Accept()
		if err != nil {
			ch <- result{err: fmt.Errorf("accept callback connection: %w", err)}
			return
		}
		defer conn.Close()

		data, err := io.ReadAll(conn)
		if err != nil {
			ch <- result{err: fmt.Errorf("read callback payload: %w", err)}
			return
		}
		ch <- result{url: string(data)}
	}()

	select {
	case res := <-ch:
		return res.url, res.err
	case <-time.After(timeout):
		return "", fmt.Errorf("timed out after %s waiting for browser callback", timeout)
	}
}

// DeliverCallback connects to the waiting add_character flow's delivery
// socket and hands it the full redirect URL. Called by the
// callback-handler subcommand, which the OS launches in a separate process
// on URL-scheme activation.
func DeliverCallback(rawURL string) error {
	path, err := callbackSocketPath()
	if err != nil {
		return err
	}
	conn, err := net.Dial("unix", path)
	if err != nil {
		return fmt.Errorf("connect to callback socket: %w", err)
	}
	defer conn.Close()

	if _, err := conn.Write([]byte(rawURL)); err != nil {
		return fmt.Errorf("write callback payload: %w", err)
	}
	return nil
}

// ExportedCallbackListener exposes callbackListener for external tests.
type ExportedCallbackListener struct {
	inner *callbackListener
}

// Delivery returns the delivery listener, for passing to ExportedReceiveCallback.
func (e *ExportedCallbackListener) Delivery() net.Listener {
	return e.inner.delivery
}

// Close releases both sockets and removes their files.
func (e *ExportedCallbackListener) Close() error {
	return e.inner.Close()
}

// CloseWithoutRemovingFiles closes the underlying listeners without
// unlinking their socket files, for tests simulating a crashed process.
func (e *ExportedCallbackListener) CloseWithoutRemovingFiles() {
	e.inner.lock.Close()
	e.inner.delivery.Close()
}

// ExportedListenForCallback exposes listenForCallback for external tests.
func ExportedListenForCallback(lockPath, deliveryPath string) (*ExportedCallbackListener, error) {
	l, err := listenForCallback(lockPath, deliveryPath)
	if err != nil {
		return nil, err
	}
	return &ExportedCallbackListener{inner: l}, nil
}

// ExportedReceiveCallback exposes receiveCallback for external tests.
func ExportedReceiveCallback(l net.Listener, timeout time.Duration) (string, error) {
	return receiveCallback(l, timeout)
}
```

```go
package sso

import (
	"context"
	"errors"
	"fmt"
	"net/url"
	"os/exec"
	"runtime"
	"sync"
	"time"

	goesi "github.com/fnt-eve/goesi-openapi"
	"golang.org/x/oauth2"

	"github.com/rusher2004/new-eden-agent-toolkit/creds"
)

// addCharacterMu closes the same-process version of a narrow TOCTOU window
// in the socket-level collision check (see Task 6's review): without it,
// two goroutines calling addCharacter at nearly the same instant could both
// pass the liveness probe before either finishes binding. TryLock makes
// that check atomic and immediate, no timing window at all, for callers in
// this process. It does not protect against two separate neat OS processes
// racing — accepted as a narrow residual limitation.
var addCharacterMu sync.Mutex

// RedirectURI is the ESI OAuth2 redirect URI registered for this app.
const RedirectURI = "eveauth-neat://callback"

// callbackTimeout bounds how long AddCharacter waits for the browser
// callback. Overridable in tests.
var callbackTimeout = 5 * time.Minute

// openBrowser launches the user's default browser at rawURL. Overridable
// in tests so no real browser is launched during automated runs.
var openBrowser = func(rawURL string) error {
	var cmd *exec.Cmd
	switch runtime.GOOS {
	case "darwin":
		cmd = exec.Command("open", rawURL)
	case "windows":
		cmd = exec.Command("rundll32", "url.dll,FileProtocolHandler", rawURL)
	default:
		cmd = exec.Command("xdg-open", rawURL)
	}
	if err := cmd.Start(); err != nil {
		return fmt.Errorf("launch browser: %w", err)
	}
	return nil
}

// oauthConfig is the subset of *goesi.Config's behavior AddCharacter needs.
// Defined here rather than imported from goesi so tests can substitute a
// fake with no network or JWT-verification dependency.
type oauthConfig interface {
	AuthURL(state string, scopes []string) string
	Exchange(ctx context.Context, code, state, expectedState string) (*oauth2.Token, *goesi.ESIJWTClaims, error)
}

// AddCharacter runs the full OAuth2/PKCE flow for a new character: opens
// the browser, waits for the callback, exchanges the code, and persists
// the refresh token.
func AddCharacter(ctx context.Context, clientID string, scopes []string) (Character, error) {
	cfg, err := newOAuthConfig(ctx, clientID)
	if err != nil {
		return Character{}, fmt.Errorf("build OAuth config: %w", err)
	}
	return addCharacter(ctx, cfg, scopes)
}

func newOAuthConfig(ctx context.Context, clientID string) (oauthConfig, error) {
	keyFunc, err := goesi.ESIDefaultKeyfunc(ctx)
	if err != nil {
		return nil, fmt.Errorf("fetch ESI JWT signing keys: %w", err)
	}
	cfg, err := goesi.NewConfig(clientID, RedirectURI, &keyFunc)
	if err != nil {
		return nil, fmt.Errorf("build ESI OAuth2 config: %w", err)
	}
	return cfg, nil
}

func addCharacter(ctx context.Context, cfg oauthConfig, scopes []string) (Character, error) {
	if !addCharacterMu.TryLock() {
		return Character{}, ErrAddCharacterInProgress
	}
	defer addCharacterMu.Unlock()

	lockPath, err := callbackLockPath()
	if err != nil {
		return Character{}, err
	}
	deliveryPath, err := callbackSocketPath()
	if err != nil {
		return Character{}, err
	}

	listener, err := listenForCallback(lockPath, deliveryPath)
	if err != nil {
		return Character{}, err
	}
	defer listener.Close()

	state, err := generateState()
	if err != nil {
		return Character{}, fmt.Errorf("generate state: %w", err)
	}

	if err := openBrowser(cfg.AuthURL(state, scopes)); err != nil {
		return Character{}, fmt.Errorf("open browser: %w", err)
	}

	rawCallback, err := receiveCallback(listener.delivery, callbackTimeout)
	if err != nil {
		return Character{}, err
	}

	code, gotState, err := parseCallback(rawCallback)
	if err != nil {
		return Character{}, err
	}

	token, claims, err := cfg.Exchange(ctx, code, gotState, state)
	if err != nil {
		return Character{}, fmt.Errorf("exchange authorization code: %w", err)
	}

	characterID, err := characterIDFromClaims(claims)
	if err != nil {
		return Character{}, err
	}

	if err := creds.SaveCharacterRefreshToken(characterID, token.RefreshToken); err != nil {
		return Character{}, fmt.Errorf("save refresh token: %w", err)
	}

	return Character{ID: characterID, Name: claims.Name}, nil
}

func parseCallback(rawURL string) (code, state string, err error) {
	u, err := url.Parse(rawURL)
	if err != nil {
		return "", "", fmt.Errorf("parse callback URL: %w", err)
	}
	q := u.Query()
	code = q.Get("code")
	state = q.Get("state")
	if code == "" {
		return "", "", errors.New("callback URL missing code parameter")
	}
	if state == "" {
		return "", "", errors.New("callback URL missing state parameter")
	}
	return code, state, nil
}

// ExportedAddCharacter exposes addCharacter for external tests.
func ExportedAddCharacter(ctx context.Context, cfg interface {
	AuthURL(state string, scopes []string) string
	Exchange(ctx context.Context, code, state, expectedState string) (*oauth2.Token, *goesi.ESIJWTClaims, error)
}, scopes []string) (Character, error) {
	return addCharacter(ctx, cfg, scopes)
}

// SetOpenBrowserForTest overrides the browser launcher for tests.
func SetOpenBrowserForTest(fn func(rawURL string) error) {
	openBrowser = fn
}

// ResetOpenBrowserForTest restores the real browser launcher. Since the
// real implementation is only ever assigned once (as openBrowser's
// initializer), tests must not depend on running before any other test has
// overridden it — resetting re-assigns the same real logic inline.

		var cmd *exec.Cmd
		switch runtime.GOOS {
		case "darwin":
			cmd = exec.Command("open", rawURL)
		case "windows":

		default:
			cmd = exec.Command("xdg-open", rawURL)
		}
		if err := cmd.Start(); err != nil {
			return fmt.Errorf("launch browser: %w", err)
		}
		return nil
	}
}

func SetCallbackTimeoutForTest(d time.Duration) {
	callbackTimeout = d
}

// ResetCallbackTimeoutForTest restores the real 5-minute callback timeout.

}
```
